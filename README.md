# DCH Designer

Web app for designing a Direct Contact Heater (DCH) for sugar plants.
Design method: sugarprocesstech.com/direct-contact-heater-design

- Calculates vapour demand, nozzle sizes, baffles, shell and height
- GA / Details A–F / plate-development drawings (export DXF, SVG, PDF)
- Weight estimate and BOM (CSV)

Usage: open `index.html` in Chrome or Edge, or open the GitHub Pages URL.
No installation, no server. The app is a single HTML file.

> PRELIMINARY design tool. Pressure parts must be verified to ASME VIII Div.1 before fabrication.
